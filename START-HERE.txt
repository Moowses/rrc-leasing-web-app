RRC WEBSITE — IT HANDOVER

Folder guide:
- Front end — new Next.js + Tailwind site for local testing.
- Backend — Fastify API, PostgreSQL/Prisma setup, and backend configuration.
- docs — current database relationships and branding reference.
- Archive — older website/handover files, presentation tools, and superseded notes.

To test the new site without automatic code refresh, start PostgreSQL if
needed, then open two PowerShell windows. Stop any existing app servers with
Ctrl+C before starting these commands (the ports must be available):

Window 1 — API:
  cd "D:\RRC-Website-IT-Handover\Backend"
  npm run preview

Window 2 — front end:
  cd "D:\RRC-Website-IT-Handover\Front end"
  npm run preview

Open http://localhost:4181. Keep both windows open; press Ctrl+C in each to
stop its server. The API runs locally on port 4180. Do not expose it publicly.

The preview commands build and run a fixed version of the app. Source-file
edits take effect after stopping and running preview again. For coding only,
use npm run dev; that mode deliberately watches files and refreshes on edits.

Read the README.md in Front end and Backend for setup details.
For Windows Server deployment, follow docs/WINDOWS-DEPLOYMENT.md.
Database relationships are in docs/DATA-MODEL.md; branding is in docs/BRANDING.md.

The cleanup archive is Archive/2026-10-12-cleanup. Its CONTENTS.json records
what was moved and why. Archived files can be recovered from that folder.

node_modules, .next, and dist are generated dependencies/build output used
for local running and builds. Backend/backups contains database backups.
